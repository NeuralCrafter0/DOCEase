# Bundled images

- `google_g_logo.png`: 96 x 96 Google "G" for the "Continue with Google" button
  (shown at 24 dp). Rasterized from
  https://commons.wikimedia.org/wiki/File:Google_%22G%22_logo.svg. The logo is
  a Google trademark, used here only on the Google sign-in button, as Google's
  sign-in branding guidelines allow.
  Bundled so it shows offline. The app used to load a 1200px Wikimedia
  thumbnail, and Wikimedia now refuses that size (HTTP 400).
